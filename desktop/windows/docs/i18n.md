# Interface translation

The renderer translates UI text with `src/renderer/src/lib/i18n.ts`. Catalogs live in
`src/renderer/src/lib/i18n/<lang>.json` and are keyed by the English source text, the
same convention as the macOS app's `Localizable.strings`. A missing entry shows English.

## Writing UI text

```tsx
import { t, tc, uiLocale } from '../lib/i18n'

<button>{t('Save')}</button>
<p>{t('{count} tasks due today', { count })}</p>
// Same English word, different meaning: key is `task-filter|open`.
<button>{tc('task-filter', 'open')}</button>
// Dates and numbers follow the chosen UI language.
new Date(ts).toLocaleDateString(uiLocale(), { month: 'short', day: 'numeric' })
```

- Plurals: branch on the count and pass each full sentence to `t()`
  (`n === 1 ? t('{count} memory', …) : t('{count} memories', …)`), never `memor${…}`.
- Use named placeholders so translators can reorder them.
- Keep `t()` out of strings sent to the backend or an LLM; translate only what is
  rendered.
- Never call `t()` at module scope: catalogs load asynchronously before the first
  render, after modules are evaluated. For config objects use a getter
  (`get label() { return t('Home') }`); for lists, a function.

## Language selection

Settings → General → App language stores `uiLanguage` (`system`, `en`, `es`, `pt-BR`)
in preferences. `system` follows the OS language (any `pt-*` OS language uses `pt-BR`). The language is fixed per window load, and its catalog is a lazy chunk the window
loads before its first render (English loads none);
changing it reloads the main window, the bar, and the insight toast
(`installUiLanguageReload`). The capture window has no UI text and is not reloaded.

## Keeping catalogs complete

```bash
node scripts/i18n-report.mjs          # missing and unused keys (Spanish)
node scripts/i18n-report.mjs --lang=pt-BR
node scripts/i18n-report.mjs --json   # missing keys as JSON to fill in
```

`lib/i18n.test.ts` checks that every catalog entry is non-empty, keeps the same
`{placeholders}` as its English key, and that all catalogs cover the same keys.

Adding a language: copy `es.json`, translate the values, and add the code to
`UiLanguage`, `UiLanguagePreference`, `UI_LANGUAGES`, `catalogs`, and
`resolveUiLanguage`.
